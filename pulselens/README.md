# PulseLens
Экспериментальное Android-приложение: фотоплетизмография через камеру и фонарик. Показывает ориентировочный BPM, интервалы между пульсовыми пиками, вариабельность, график сигнала. **Не ЭКГ, не диагностика аритмий.** Движение, автоэкспозиция и плохой контакт могут вызывать ложную нерегулярность. При повторных перебоях требуется ЭКГ.
Для сборки: `cd pulselens && gradle :app:assembleDebug`. APK в `pulselens/app/build/outputs/apk/debug/app-debug.apk`.
